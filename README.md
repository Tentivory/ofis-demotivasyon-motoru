# Ofis Demotivasyon Motoru

## Giriş

Bu proje, modern ofis hayatının gerçeklerini yansıtan devrim niteliğinde bir yazılımdır. Geleneksel motivasyon posterleri ve "Takım Çalışması!" sloganlarının aksine, **Ofis Demotivasyon Motoru** size gerçeği söyler:

> Hiçbir şey değişmeyecek. Sen yine de dene.

## Neden Bu Motor?

- **Gerçekçilik:** Motivasyon yalanları yerine dürüst umutsuzluk.
- **Verimlilik:** Demotive olmuş çalışanlar daha az beklentiye sahip olur, dolayısıyla daha az hayal kırıklığı yaşar.
- **Bilimsel Temel:** Rastgele seçilmiş cümleler. (Bu bile bir bilimdir.)
- **HR Uyumlu Değil:** Tam olarak istediğiniz gibi.

## Kurulum

```bash
git clone https://github.com/Tentivory/ofis-demotivasyon-motoru.git
cd ofis-demotivasyon-motoru
python demotivasyon.py
```

Python 3.x yeterlidir. Başka hiçbir şeye ihtiyacınız yok. Çünkü zaten hiçbir şey işe yaramaz.

## Kullanım

Programı çalıştırın, bugün yapmak zorunda olduğunuz görevi yazın, ve hayatın acı gerçekleriyle yüzleşin.

Örnek:
```
Bugün ne yapmak zorundasın? (çıkmak için 'q'): Rapor yazmak
>> 'Rapor yazmak' mı? Harika. Şimdi bunu yaparken 3 saat boyunca ekrana bakıp hiçbir şey başarmak zorundasın.
```

## Katkıda Bulunma

Katkıda bulunmayın. Bu motor zaten yeterince demotive edici. Ekstra bir şey eklemek sadece herkesi daha da üzültür.

Eğer illa bir şey yapmak istiyorsanız, bir issue açın ve "Bu da işe yaramayacak" yazın. Onaylanırsınız.

## Lisans

Bu proje MIT lisansı altındadır. Yani istediğinizi yapabilirsiniz. Ama muhtemelen yapmayacaksınız. Çünkü motive değilsiniz.

## İletişim

Herhangi bir sorunuz varsa, sorun. Cevap vermeyebiliriz. Bu da demotivasyonun bir parçasıdır.
